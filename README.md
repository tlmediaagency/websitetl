# TL Media Agency — static website

Strategic Operations Partner site. Plain HTML/CSS/JS for GitHub Pages.

## Deploy

Upload the **contents of this folder** to the repo root (index.html at the top).
Settings → Pages → Deploy from `main` / `/ (root)`.
Custom domain: tlmediallc.net (add a CNAME file if needed).

GEO files at root: `llms.txt`, `llms-full.txt`, `robots.txt`, `sitemap.xml`.
