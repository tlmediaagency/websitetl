# TL Media Agency — static website

Plain HTML, CSS, and JavaScript. Ready for GitHub Pages. No build step.

## Files

- index.html, about.html, services.html, who-we-serve.html
- brainstorm-brew.html, faq.html, contact.html, brand-guide.html
- css/styles.css
- js/main.js
- images/ (logo, icons, portrait)
- favicon.svg

## GitHub Pages

1. Create a repo.
2. Upload the contents of this folder to the repo root (keep index.html at the top).
3. Settings → Pages → Deploy from branch `main`, folder `/ (root)`.

HoneyBook forms on Contact and Brainstorm Brew use placement id `6308c982d2ebe70007fedc1e`.
Fonts load from Google Fonts: Cormorant Garamond + Outfit.
